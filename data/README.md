# Data

## Included: Study 3 panel

`study3_climate_pilot.dta` (21,157 firm-years, 2,921 firms, 2011–2023) is the
estimation sample for Study 3, the Climate-Adaptive City Pilot. With the
versions pinned in `requirements.txt`, this command reproduces the Study 3
results in the main README exactly:

    python run_dml.py configs/study3_climate_pilot.yaml

To keep the file small and anonymous it is trimmed:

* it contains only the 12 regression columns: `SCR`, `did`, `id`, `year` and the 8 controls;
* firm identifiers are re-coded to `1..N`, with the original order preserved so that the cross-fitting folds are identical;
* no firm names, stock codes or locations are included.

| Variable | Meaning |
|---|---|
| `SCR` | Supply chain resilience index (entropy method) |
| `did` | Treat × Post: firm in a pilot city × year ≥ 2017 |
| `id`, `year` | Anonymised firm id, year |
| `Size`, `Lev`, `ROA`, `FirmAge`, `Dual`, `FIXED`, `Growth`, `Board` | Controls: firm size, leverage, return on assets, firm age, CEO–chair duality, fixed-asset ratio, sales growth, board size |

## Synthetic data

`synthetic_did.csv` is generated by `python make_synthetic_data.py` and is used
by `configs/demo_synthetic.yaml` (known true effect = 0.5).

Any `.dta`, `.csv` or `.parquet` panel works: point a new config at it and set
the outcome, treatment, id, time and control columns.
